# User Stories – Läslistan

## US01 – Visa bokkatalogen

Som användare vill jag öppna Katalog så att jag kan se böckerna på sidan.

**Acceptanskriterier:**
- Användaren kan öppna webbsidan.
- Böckerna visas i katalogen.

## US02 – Öppna Mina böcker

Som användare vill jag öppna Mina böcker så att jag kan se mina favoritböcker.

**Acceptanskriterier:**
- Användaren kan klicka på Mina böcker.
- Sidan Mina böcker visas.

## US03 – Visa statistik

Som användare vill jag öppna Statistik så att jag kan se statistik om böckerna.

**Acceptanskriterier:**
- Användaren kan klicka på Statistik.
- Statistiksidan visas.

## US04 – Öppna formuläret

Som användare vill jag öppna formuläret för att lägga till en bok så att jag kan skriva information om boken.

**Acceptanskriterier:**
- Användaren kan klicka på Lägg till bok.
- Formuläret visas.
- Det finns fält för titel och författare.

## US05 – Lägga till en bok

Som användare vill jag lägga till en bok med titel och författare så att boken visas i katalogen.

**Acceptanskriterier:**
- Användaren kan skriva titel och författare.
- Användaren kan klicka på Lägg till ny bok.
- Den nya boken visas i katalogen.

## US06 – Kontrollera formuläret

Som användare vill jag fylla i titel och författare innan jag lägger till en bok så att informationen inte saknas.

**Acceptanskriterier:**
- Formuläret har fält för titel och författare.
- Knappen är inaktiverad när fälten är tomma.

## US07 – Markera favoritböcker

Som användare vill jag markera böcker som favoriter så att jag kan spara böcker som jag gillar.

**Acceptanskriterier:**
- Användaren kan markera en bok som favorit.
- Användaren kan markera två eller flera böcker som favoriter.

## US08 – Se favoritböcker

Som användare vill jag se mina favoritböcker på Mina böcker så att jag kan hitta dem enkelt.

**Acceptanskriterier:**
- Användaren kan öppna Mina böcker.
- Favoritböckerna visas på sidan.

## US09 – Ta bort favoritbok

Som användare vill jag ta bort en bok från favoriter så att jag kan ändra min favoritlista.

**Acceptanskriterier:**
- Användaren kan klicka på favoritknappen igen.
- Boken tas bort från favoritlistan.
- De andra favoritböckerna finns kvar.
