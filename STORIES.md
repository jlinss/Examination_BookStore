User Stories – Läslistan

US01 – Visa bokkatalogen
 - Som användare vill jag kunna öppna Katalog så att jag kan se böckerna i Läslistan.

 Acceptanskriterier:

        Användaren öppna webbsidan
        Katalogens innehåll visas.

US02 – Öppna formuläret för att lägga till en ny bok
 - Som användare vill jag kunna öppna Lägg till bok så att jag kan lägga till en ny bok.

 Acceptanskriterier:

        Användaren kan klicka på Lägg till bok.
        Ett formulär för att lägga till en bok visas.

US03 – Visa mina böcker
Som användare vill jag kunna öppna Mina böcker så att jag kan se mina favoriter böcker.

Acceptanskriterier:

        Användaren kan klicka på Mina böcker.
        Sidan Mina böcker visas.

US04 – Visa statistik

Som användare vill jag kunna öppna Statistik så att jag kan ta del av information om böckerna och favoriter böcker.

Acceptanskriterier:

        Användaren kan klicka på Statistik.
        Statistikvyn visas.
